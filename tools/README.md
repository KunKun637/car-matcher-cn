# 公开车系目录更新器

`update-models.py` 依次读取汽车之家无需登录即可访问的 A–Z 车型索引页，生成网站可直接加载的 `models.generated.js`。

它只保留以下公开事实字段：车系 ID、车系名、品牌、厂商、公开指导价区间和来源链接；不复制图片、文章、口碑或用户数据。脚本共请求 26 个索引页，默认每次请求间隔 0.4 秒。

```powershell
python car-matcher/tools/update-models.py
```

收录规则是“索引页中存在红色当前指导价，且车系链接未被标记为灰色历史链接”。因此它代表公开页面在更新时点列出的有价车系，不声称覆盖未上市、停售、平行进口、区域限定或页面尚未收录的车辆。

数据源：[汽车之家公开车型索引](https://www.autohome.com.cn/grade/carhtml/)
